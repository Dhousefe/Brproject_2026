Sistema Inteligente de Voto & Entrega Automatizada

Esta documentação detalha a arquitetura completa da integração por webhook com o Top L2JBrasil no BrProject-2026. O sistema permite que jogadores votem no ranking oficial, vinculem o personagem com 1 clique através de um card retrátil inovador, e recebam suas recompensas no jogo instantaneamente de forma segura e à prova de falhas.

02

Fluxo de Execução em 7 Etapas Autoexplicativas

Etapa 1 Frontend / Ktor

Carregamento e Verificação de Cooldown

O site consulta GET /api/vote/info passando o IP e token da conta. A API verifica se o jogador já votou nas últimas 12 horas. Se estiver livre, a esfera #vote-orb-card exibe o status "VOTE - Disponível para Votar".

Etapa 2 Interface Modal

Seleção do Personagem com 1 Clique

Ao clicar no Card Retrátil, o modal estilizado é aberto via GSAP. Se logado, lista todos os personagens da conta com seus níveis e classes. Para visitantes, disponibiliza um campo simples para digitar o nome do personagem.

Etapa 3 Game API

Geração do Token de Rastreamento

Ao clicar em "Votar no Top L2JBrasil", o frontend envia POST /api/vote/intent. O servidor cria uma chave de rastreamento temporária de 15 minutos em memória, vinculando o IP do votante ao personagem selecionado.

Etapa 4 Navegador / Top L2J

Abertura Segura em Nova Aba

O navegador abre a URL oficial do Top L2JBrasil em uma nova aba com o parâmetro de retorno configurado. O jogador resolve o captcha do Top L2JBrasil e confirma o voto no ranking.

Etapa 5 Radar Frontend

Radar de Aguardo & Sincronização

Enquanto o jogador vota na outra aba, o modal ativa uma animação de radar pulsante e inicia uma verificação leve em background a cada 3,5 segundos aguardando a confirmação do webhook.

Etapa 6 Webhook Seguro

Recepção do Webhook & Timing-Safe

O Top L2JBrasil dispara POST /api/vote/webhook/l2jbrasil com o header X-L2JBrasil-Token. O Ktor valida o token com comparação de tempo constante para evitar ataques de temporização e checa duplicidade em site_vote_logs.

Etapa 7 · Conclusão Game Server & Visual

Entrega Instantânea dos Itens + Celebração Visual 🎉

Se o personagem estiver online, os itens configurados são depositados imediatamente no inventário via reflexão segura, tocando o som oficial de quest (ItemSound.quest_finish) e enviando mensagem no meio da tela. Se estiver offline, os itens são gravados com segurança na tabela SQL items. O servidor realiza anúncio global e a página web comemora o sucesso!

Garantias de Segurança & Proteção Anti-Fraude

🛡️ Timing-Safe Compare

O token do cabeçalho X-L2JBrasil-Token é validado utilizando MessageDigest.isEqual em tempo constante (O(1)), eliminando qualquer vetor de ataque por análise de tempo de resposta.

🔒 Deduplicação Idempotente

Cada entrega registra o delivery_id na tabela site_vote_logs com índice único. Se o Top L2JBrasil reenviar o mesmo webhook nas tentativas automáticas, a duplicidade é rejeitada com segurança.

⚡ Tolerância a Falhas

Se o jogador fechar o cliente do jogo ou a internet oscilar no instante do voto, a transação SQL atômica na tabela items garante a entrega mesmo com o personagem 100% offline.
