🔍 1. Diagnóstico da Causa Raiz: Por que os HTMLs não eram localizados?

Embora todas as 341 pastas de quests (ex: Q001_LettersOfLove a Q688_DefeatTheElrokianRaiders) estivessem perfeitamente estruturadas em game/data/locale/en_US/html/script/quest/, qualquer interação com NPCs de quest resultava no erro:
"Not found file: ./data/locale/en_US/html/script/quest/Q001_LettersOfLove/30048-01.htm".

❌ O Mecanismo da Falha (Chave Corrompida)

Divergência de Chaves: Em Quest.java:1463, o método getHtmlText() construía a chave prefixando "./data/locale/en_US/".

No entanto, o carregador HTMLData.java indexa os arquivos de forma relativa à pasta do locale (localeBasePath.relativize(file)), armazenando chaves limpas como "html/script/quest/Q001_LettersOfLove/30048-01.htm".

A busca literal no HashMap falhava em 100% das vezes, pois a string buscada nunca existiria no mapa.

✅ A Solução em 4 Níveis (Blindagem Total)

Padronização Canônica: Quest.java agora gera o caminho canônico universal "html/script/quest/" + getName() + "/" + fileName.

Motor de Normalização (normalizeKey): O HTMLData higieniza slashes, retira ./ e extrai a partir de html/ tornando o sistema tolerante a qualquer prefixo legado.

Padrão Cache-Aside (Fallback ao Disco): Se um arquivo não estiver em memória, o HTMLData verifica e carrega do disco sob demanda, garantindo zero janelas de falha.

🔒 3. Arquitetura do Motor de Contingência e Normalização em 4 Níveis

Para erradicar qualquer possibilidade de regressão ou falha de localização de templates, a camada de acesso a dados opera agora sob uma arquitetura de defesa em profundidade: 

flowchart TD
    Req[Requisicao de Template: Quest / Bypass / Script / Npc] --> Norm[Nivel 1: normalizeKey - Sanitizacao de Slashes e Extracao html/]
    
    Norm --> MemCheck{Nivel 2: Template existe na memoria do Locale?}
    MemCheck -->|Sim: Hit L1| ReturnContent[Retorna Conteudo Imediatamente]
    
    MemCheck -->|Nao: Miss| DefaultMemCheck{Template existe no Locale Padrao en_US?}
    DefaultMemCheck -->|Sim: Hit L2| ReturnContent
    
    DefaultMemCheck -->|Nao: Miss| DiskCheck{Nivel 3: Cache-Aside - Arquivo existe no disco do Locale?}
    DiskCheck -->|Sim: Encontrado| ReadAndCache[Le do disco + Popula _data no Locale]
    ReadAndCache --> ReturnContent
    
    DiskCheck -->|Nao: Nao existe| DefaultDiskCheck{Arquivo existe no disco do Locale Padrao?}
    DefaultDiskCheck -->|Sim: Encontrado| ReadAndCacheDefault[Le do disco + Popula _data no Default]
    ReadAndCacheDefault --> ReturnContent
    
    DefaultDiskCheck -->|Nao: Inexistente| ErrorHtml[Nivel 4: Not found file seguro e auditado]

Normalização Defensiva (HTMLData.normalizeKey)

public static String normalizeKey(String file) { if (file == null) return null; String normalized = file.replace('\\', '/').trim(); while (normalized.startsWith("./")) normalized = normalized.substring(2); final int htmlIdx = normalized.indexOf("html/"); if (htmlIdx != -1) normalized = normalized.substring(htmlIdx); return normalized; }

📋 5. Casos de Uso Validados (Zero Regressão)

[UC1] Talk Inicial de Quest

Cenário: Jogador interage com NPC inicial (ex: Darin 30048) e seleciona a Quest de nível 1.

Garantia: getHtmlText resolve para html/script/quest/Q001_LettersOfLove/30048-01.htm, exibindo o diálogo inicial com botões de aceite.

[UC2] Bypass de Progresso (onAdvEvent)

Cenário: Jogador clica no botão "Accept Quest" (30048-06.htm).

Garantia: onAdvEvent transiciona o estado para STARTED, entrega o item e abre o template subsequente sem interrupções.

[UC3] Suporte Multi-Locale Transparente

Cenário: Jogador configurado em Português (pt_BR) abre uma quest que ainda só possui arquivos em inglês.

Garantia: O fallback automático do HTMLData entrega a versão en_US imediatamente sem telas de erro.

[UC4] Tradução Automática DeepL

Cenário: Jogador com o mod de tradução automática ativado.

Garantia: O DeeplTranslator recebe caminhos canônicos normalizados (html/script/quest/...) permitindo a tradução dinâmica e salvamento sem erros de caminho duplicado.

[UC5] Scripts Customizados & AIs

Cenário: Scripts de Siege, Kamaloka, Rainbow Springs Chateau ou Chefes que utilizam isRealQuest == false.

Garantia: Mantêm seu formato nativo html/script/siegablehall/... sem alteração, preservando 100% de compatibilidade.

[UC6] Inicialização e Hot Reload Seguro

Cenário: Boot do servidor ou execução de //reload html.

Garantia: A barreira CompletableFuture.allOf() assegura que 100% dos arquivos estejam em memória antes de qualquer interação, com log informativo auditável.
